# 🔗 Flask URL Shortener

Shorten URLs, track clicks, manage expiry dates, and access analytics with a simple and secure Flask web application.

## ✨ Features
- User Authentication (Register/Login/Logout)
- URL Shortening
- Click Analytics
- Automatic URL Expiry
- REST API
- Secure Password Hashing
- SQLite Database

## 🛠️ Built With
- Python
- Flask
- SQLite
- HTML
- CSS
